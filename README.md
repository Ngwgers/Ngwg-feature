# Ngwg-feature

must-load 插件，只实现 **ngwg-helper-v1** 协议——为主题开发者提供常用工具。

| helper | 用途 |
| --- | --- |
| `formatDate(date, fmt)` | 日期格式化（`YYYY MM DD HH mm ss`） |
| `archives(posts)` | 按年分组的归档结构 |
| `tagCloud(tags)` / `categoryTree(cats)` | 带计数的标签/分类列表（按数量排序） |
| `excerpt(post, len)` | 纯文本摘要（剥标签、截断） |
| `limit(arr, n)` | 取前 N 项 |
| `slugify(s)` | URL 安全 slug（与 Core 生成的目录名一致） |
| `postsWithTag(site, tag)` / `postsInCategory(site, cat)` | 按标签/分类取文章 |
| `t(key, args…)` | i18n 翻译：`{{@ t "archive.subtitle" site.posts.length }}`，`{0}` 被参数替换（需 i18n 主题，见 Ngwg-docs/theme-development.md） |

`buildData` 钩子还会把 `recent`（最近文章 slug）、`totalPosts`、`totalWords`
注入 `site.extra`。

模板中调用：`{{@ formatDate page.meta.date "YYYY-MM-DD" }}`。

## English

# Ngwg-feature

A must-load plugin that only implements the **ngwg-helper-v1** protocol — providing common utilities for theme developers.

| helper | Purpose |
| --- | --- |
| `formatDate(date, fmt)` | Date formatting (`YYYY MM DD HH mm ss`) |
| `archives(posts)` | Archive structure grouped by year |
| `tagCloud(tags)` / `categoryTree(cats)` | Tag/category lists with counts (sorted by count) |
| `excerpt(post, len)` | Plain-text excerpt (tags stripped, truncated) |
| `limit(arr, n)` | Take the first N items |
| `slugify(s)` | URL-safe slug (consistent with directory names generated by Core) |
| `postsWithTag(site, tag)` / `postsInCategory(site, cat)` | Fetch posts by tag/category |
| `t(key, args…)` | i18n translation: `{{@ t "archive.subtitle" site.posts.length }}`, `{0}` is replaced by the argument (requires an i18n theme, see Ngwg-docs/theme-development.md) |

The `buildData` hook also injects `recent` (recent post slugs), `totalPosts` and `totalWords` into `site.extra`.

Call it in templates: `{{@ formatDate page.meta.date "YYYY-MM-DD" }}`.
